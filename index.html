Competitor ad monitor

See which new Meta and TikTok ads your App Store competitors are running. Paste one or more paid-ad search responses below (a JSON object, an array of them, or one object per line). Duplicates across pages are merged. Nothing leaves your browser.

Where to get the JSON

The input is the paid-ad search response from PeekPanda, which stores dated observations from the public Meta and TikTok ad libraries and links each ad to the App Store app it points to. Ask for the ads verified to link to your rivals, newest finds first:

curl --get https://api.peekpanda.com/v1/paid-ads \
  -H "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --data-urlencode 'storeIds=1000000001,1000000002' \
  --data-urlencode 'sort=recently_discovered' \
  --data-urlencode 'limit=40'

Over MCP this is the get_ads tool with action search. You need a PeekPanda account. The scheduled competitor ads guide explains the discoveredAfter loop this page and the CLI follow.

How to read it: "Found" is when PeekPanda first recorded the ad, not when the advertiser started it ("Started", where the source discloses it). Run days count a live ad to today and a stopped ad to its disclosed end. There is no spend figure. An empty result does not prove a rival stopped advertising.

A command-line version that remembers the last run, writes Markdown or CSV and pings Slack or Discord lives in the GitHub repo.
